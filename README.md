## Evidence model

Records may use one or more of these evidence types:

- **Accepted digital donation** — the institution directly confirms acceptance of a digital work.
- **Catalogue inclusion** — the work has a bibliographic or discovery record in the institution's catalogue.
- **Institutional resource inclusion** — the institution has deliberately added the work to an official library resource, guide, reading, or access page.
- **Acknowledged donation** — receipt has been confirmed, but cataloguing or public inclusion is still pending.

Institutional confirmation may exist in private correspondence. Private emails, personal addresses, screenshots of correspondence, and other non-public communications are **not uploaded to this repository**. Where relevant, the public record states that direct institutional confirmation is retained privately by the author.

## Preservation

Public web evidence can be preserved through the `Archive URL` GitHub Action. A capture may include:

- SingleFile HTML snapshot;
- full-page screenshot;
- raw HTML fallback;
- metadata;
- SHA-256 checksums;
- an optional Internet Archive / Wayback Machine URL.

This creates three complementary evidence layers:

1. the institution's live public page;
2. an independent third-party archival snapshot where available;
3. an author-maintained GitHub snapshot with immutable Git history and checksums.

## Scope

This repository documents institutional actions concerning specific publications. It does not imply institutional endorsement of the author's views, affiliation with the institution, or academic peer review unless explicitly evidenced separately.
